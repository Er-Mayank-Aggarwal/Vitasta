1
Create Database on Neon (Free Tier)
Database

Neon provides a serverless PostgreSQL database with pooled connections to store your sarees, orders, patron shortlist, addresses, and customer reviews.

  1. Go to https://neon.tech and click "Sign Up" (you can sign up with your Google or GitHub account).
  2. Click "Create a Project":
    • Project name: vitasta-atelier
    • Region: Select Asia Pacific (Singapore) or closest to India.
    • Postgres version: Default (16 or 17).
  3. Click "Create Project".
  4. On the dashboard under Connection Details:
    • Check the box for "Pooled connection" (required for serverless scaling).
    • Select Prisma or Node.js connection string format.
  5. Copy your entire connection string. It will look like this:
# Your DATABASE_URL:
DATABASE_URL="postgresql://neondb_owner:YOUR_PASSWORD@ep-young-dust-aoun8xk9-pooler.c-2.ap-southeast-1.aws.neon.tech/neondb?sslmode=require&schema=vitasta"
💡 Pro Tip: Append &schema=vitasta to the end of the connection URL to ensure all relational tables are neatly organized in your atelier schema.
2
Create Media Storage on Cloudinary (Free Tier)
Photos & Video CDN

Cloudinary provides global edge media delivery for ultra-fast 4K saree drape photography and pre-dispatch Loom inspection videos.

  1. Go to https://cloudinary.com/users/register_free and create a free account.
  2. Once logged in, look at your main Dashboard under "Product Environment Credentials".
  3. You will see three values:
    • Cloud Name (e.g. sjl1rfvu)
    • API Key (e.g. 278911177331486)
    • API Secret (click the eye icon to reveal)
CLOUDINARY_CLOUD_NAME="YOUR_CLOUDINARY_CLOUD_NAME"
CLOUDINARY_API_KEY="YOUR_CLOUDINARY_API_KEY"
CLOUDINARY_API_SECRET="YOUR_CLOUDINARY_API_SECRET"
3
Create Google 1-Click Login (Google Cloud)
Google Sign-In

Allows royal patrons to authenticate and register with one tap using their Google accounts.

  1. Go to https://console.cloud.google.com and sign in with your business Google account.
  2. Click the project dropdown at the top > click "New Project" > Name it Vitasta Saree Atelier > click Create.
  3. In the search bar, type "OAuth consent screen" and open it:
    • User Type: External > click Create.
    • App name: Vitasta Saree Atelier
    • User support email: vitastabysmita@gmail.com
    • Developer contact: Your email.
    • Click Save and Continue through the scopes and test users.
  4. In the left sidebar, click "Credentials" > click "+ CREATE CREDENTIALS" > select "OAuth client ID":
    • Application type: Web application.
    • Name: Vitasta Web Client.
    • Authorized JavaScript origins: Add your Netlify URL or custom domain (e.g. https://vitasta.luxury or https://vitasta-atelier.netlify.app).
    • Authorized redirect URIs: Add your domain followed by /api/auth/callback/google (e.g. https://vitasta.luxury/api/auth/callback/google).
  5. Click Create. A popup will display your Client ID and Client Secret.
GOOGLE_CLIENT_ID="YOUR_GOOGLE_CLIENT_ID.apps.googleusercontent.com"
GOOGLE_CLIENT_SECRET="YOUR_GOOGLE_CLIENT_SECRET"
4
Setup Razorpay Online Payment Gateway
Payments (UPI / Cards)

Accept instant online payments from patrons across India via UPI (Google Pay, PhonePe, Paytm), QR Code, Credit/Debit Cards, NetBanking, and EMI.

  1. Go to https://razorpay.com and click "Sign Up".
  2. Complete the quick business onboarding (Individual / Proprietorship / Private Limited).
  3. In your Razorpay Dashboard, navigate to Account & Settings (or Developer Controls) > API Keys.
  4. Click "Generate Key" (you can start in Test Mode or Live Mode):
    • Key ID: Starts with rzp_live_... (or rzp_test_... for testing).
    • Key Secret: Copy and store securely (displayed once upon generation).
# Razorpay Online Payment Gateway Keys:
RAZORPAY_KEY_ID="rzp_live_YOUR_KEY_ID"
RAZORPAY_KEY_SECRET="YOUR_KEY_SECRET"
NEXT_PUBLIC_RAZORPAY_KEY_ID="rzp_live_YOUR_KEY_ID"
💳 Automatic Fallback: In local testing or sandbox mode without live keys, Vitasta provides an automated demo verification handler so checkout flows can be fully tested end-to-end.
5
Deploy on Netlify via Your GitHub Repository
Live Deployment

Deploy directly from your public GitHub repository to Netlify with automatic continuous deployment on every Git push.

👑 Official GitHub Repository for Vitasta: https://github.com/Er-Mayank-Aggarwal/Vitasta
  1. Make sure your GitHub repository is set to Public (or grant Netlify access to your private repository).
  2. Go to https://app.netlify.com and sign in (using your GitHub account).
  3. Click "Add new site" > select "Import an existing project" > choose GitHub.
  4. Search and select your repository: Er-Mayank-Aggarwal/Vitasta.
  5. Under Build settings, Netlify will auto-detect Next.js:
    • Build command: npm run build (which executes prisma generate && next build)
    • Publish directory: .next
  6. Click on "Add environment variables" (or navigate to Site configuration > Environment variables).
  7. Copy and paste the entire master list below into your Netlify variables!
# =========================================================================
# MASTER ENVIRONMENT VARIABLES (Paste into Netlify Dashboard)
# =========================================================================

DATABASE_URL="postgresql://neondb_owner:YOUR_DATABASE_PASSWORD@YOUR_NEON_HOST-pooler.c-2.ap-southeast-1.aws.neon.tech/neondb?sslmode=require&schema=vitasta"
BETTER_AUTH_SECRET="fn/sIN6//a6izWd3gmKk4Dj7Y4MeMJh5+fimMHwschA="
BETTER_AUTH_URL="https://your-site.netlify.app"
NEXT_PUBLIC_APP_URL="https://your-site.netlify.app"
GOOGLE_CLIENT_ID="YOUR_GOOGLE_CLIENT_ID.apps.googleusercontent.com"
GOOGLE_CLIENT_SECRET="YOUR_GOOGLE_CLIENT_SECRET"
CLOUDINARY_CLOUD_NAME="YOUR_CLOUDINARY_CLOUD_NAME"
CLOUDINARY_API_KEY="YOUR_CLOUDINARY_API_KEY"
CLOUDINARY_API_SECRET="YOUR_CLOUDINARY_API_SECRET"
RAZORPAY_KEY_ID="rzp_live_YOUR_RAZORPAY_KEY_ID"
RAZORPAY_KEY_SECRET="YOUR_RAZORPAY_KEY_SECRET"
NEXT_PUBLIC_RAZORPAY_KEY_ID="rzp_live_YOUR_RAZORPAY_KEY_ID"
NEXT_PUBLIC_ENABLE_DEMO_LOGIN="false"
  1. Click "Deploy Vitasta".
  2. Netlify will automatically build and publish your site with a free SSL certificate!
👑 First Time Admin Access: Once deployed, your products and default admin account (admin@vitasta.com) are ready in the database. Navigate to /admin-controls to manage your orders and saree catalog!
